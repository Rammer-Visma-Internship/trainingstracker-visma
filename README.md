# Training Tracker

This project is a training tracker for employees of Visma Tech Portugal. It helps team members track and manage training activities, progress, and completion status.

## What users should know

- The tool is designed for Visma Tech Portugal employees.
- Users can view and update training records.
- The project aims to make training tracking simple and transparent.
- Data should be entered accurately to ensure correct reporting.
- Access to the tracker is intended for authorized staff only.
